# สนามเพื่อนซน 🫧🥊🖍️

เว็บไซต์เกมสีสด กดง่าย สำหรับเด็กวัย 3–4 ขวบ เล่นบนเบราว์เซอร์แบบเต็มจอได้ทันที ไม่มีเลือด ไม่มีการบาดเจ็บ เกมยิงจบด้วยการช่วยเพื่อนสัตว์ และมีเกมระบายสีแยกต่างหาก

▶ **เล่นออนไลน์:** `https://checkfile2568-ops.github.io/slingshot-pigs/`

## เกมในชุด

| เกม | วิธีเล่น | ด่าน |
|---|---|---|
| ฟองสบู่กู้ภัย 🫧 | แตะเป้าหมายหรือเล็งแล้วปล่อยฟองเพื่อเปิดกรงและช่วยสัตว์ | 3 |
| นวมเด้งช่วยเพื่อน 🥊 | แตะเป้าหมายหรือเล็งแล้วปล่อยนวมนุ่ม ๆ ให้ชนกล่องและช่วยสัตว์ | 3 |
| โลกสีรุ้ง 🖍️ | เลือกสีแล้วแตะส่วนต่าง ๆ ของภาพผีเสื้อ บ้าน หรือจรวด | 3 ภาพ |
| ถล่มป้อมหมูโจร 🐦 | เกมหนังสติ๊กเดิม | 10 |

เกมย่อยมีภาพวาดด้วย Canvas, เสียงเอฟเฟกต์, ปุ่มเริ่มด่านใหม่, ปุ่มเต็มจอ และปุ่มกลับหน้ารวมเกม ปุ่มเสียงอยู่หน้ารวมเกม ข้อมูลการผ่านด่านบันทึกเฉพาะในอุปกรณ์นี้

เกมหนังสติ๊กเดิมมีชื่อเล่นและคะแนนแยกตามชื่อเล่นในอุปกรณ์นั้น ๆ โดยไม่ส่งข้อมูลออกจากเครื่อง เลือกชื่อได้ในเมนู “ผู้เล่น / คะแนน” โดยไม่ต้องกรอกชื่อก่อนเริ่มเล่น และกดปุ่มรูปบ้านเพื่อกลับหน้ารวมเกมได้

## เกมหนังสติ๊กเดิม: ถล่มป้อมหมูโจร 🐦💥🐷

เกมหนังสติ๊กยิงนกถล่มป้อมหมูโจรยังอยู่ครบ เปิดได้จากหน้าเลือกเกม หรือโดยตรงที่ `slingshot.html` สร้างด้วย **Phaser 3.90 + Matter.js** และไม่ต้อง build

## ฟีเจอร์

| หมวด | รายละเอียด |
|---|---|
| ลากแล้วยิง | ลากนกถอยหลังแล้วปล่อย ยางยืดตามแรงดึง และมีเส้นประบอกทางที่นกจะบิน ซึ่งคำนวณด้วยสูตรเดียวกับฟิสิกส์จริง |
| บล็อกถล่ม | ฟิสิกส์ Matter.js ทำให้บล็อกล้ม หมุน และกระเด็นได้จริง ความเสียหายคิดจากแรงกระแทก บล็อกเริ่มร้าวเมื่อเสียหายเกินครึ่ง และแตกเป็นเศษเมื่อพัง |
| วัสดุ | ไม้ · กระจก · หิน · **เหล็ก** · **ลัง TNT** (ระเบิดต่อกันเป็นลูกโซ่ได้) · **หินผา** (พื้นยกสูง ทำลายไม่ได้) และมีทั้งทรงเหลี่ยม สามเหลี่ยม และลูกกลม |

| หมู 4 ชนิด | ตัวเล็ก · ปกติ · ใส่หมวกนิรภัย (ถึกขึ้น) · บอสโพกผ้าแดง |
| 10 ด่าน | ปลดล็อกทีละด่าน เก็บดาว 1–3 ดวง และบันทึกสถิติไว้ในเครื่อง (localStorage) |
| เต็มจอ | ภาพขยายเต็มหน้าต่างทุกสัดส่วนจอ ไม่มีขอบดำ มีปุ่ม/ปุ่ม F สำหรับโหมดเต็มจอ และภาพคมบนจอ Retina |
| กล้อง | เปิดฉากด้วยการแพนให้เห็นป้อม กล้องตามนกระหว่างบิน และลากพื้นที่ว่างหรือหมุนล้อเมาส์เพื่อเลื่อนดูป้อมได้ |
| กราฟิก | ฉากหลังหลายชั้นเลื่อนต่างระดับ (parallax) · เงาใต้วัตถุ · เอฟเฟกต์ระเบิด ฝุ่น เศษวัสดุ · หมูและนกกะพริบตา · เสียงสังเคราะห์ด้วย WebAudio |

## 🔧 ต่อยอด

ค้นหาคำว่า `🔧 ต่อยอด` ใน `slingshot.html` จะเจอจุดสำหรับต่อยอดเกมหนังสติ๊ก

**เพิ่มด่าน:** เพิ่ม object ใหม่ต่อท้าย `LEVELS` ได้เลย ระบบเลือกด่าน การปลดล็อก และการนับดาวจะรองรับให้อัตโนมัติ

```js
{ name: 'ด่านของฉัน', width: 1600, birds: ['pilot', 'dash', 'boom'],
  build(o) {
    // y = ระยะจากพื้นถึงขอบล่างของชิ้นงาน
    const top = room(o, 1000, 0, 160, 100, 'stone', 'wood');  // ห้อง: เสา 2 ต้น + คาน (คืนค่าความสูงขอบบน)
    o.push(pig(1000, 0, 'helmet'), pig(1000, top));
    o.push(blk('tnt', 1150, 0, 40, 40), tri('wood', 1000, top, 100, 50), ball('stone', 900, 0, 36));
    o.push(rock(1300, 0, 300, 120));                            // พื้นยกสูง (ทำลายไม่ได้)
  } },
```

| อยากเพิ่ม | แก้ที่ |
|---|---|
| วัสดุใหม่ | `MATERIALS` (ค่า hp, ความหนาแน่น, คะแนน) และเพิ่มวิธีวาดใน `drawBlock()` |
| หมูชนิดใหม่ | `PIG_TYPES` และเพิ่มหน้าตาใน `drawPig()` |
| นกชนิดใหม่ / พลังใหม่ | `BIRD_TYPES` + `drawBird()` + เพิ่ม `case` ใน `useAbility()` |
| ความแรงหนังสติ๊ก / ความเสียหาย / รัศมีระเบิด | `CFG` |

## โครงสร้างเกมหนังสติ๊ก (`slingshot.html`)

1. **ค่าคงที่และข้อมูลเกม:** `CFG`, `MATERIALS`, `PIG_TYPES`, `BIRD_TYPES`, `LEVELS`
2. **บันทึก / เสียง / เต็มจอ:** `Save` (localStorage), `Sfx` (WebAudio), `FS`
3. **กราฟิก:** ฟังก์ชัน `draw*()` วาดลง Canvas ที่ความละเอียด 2 เท่า (`Tex`)
4. **ฉาก:**
   - `BootScene` เตรียมภาพทั้งหมด
   - `TitleScene` หน้าเมนู
   - `GameScene` ตัวเกม: ฟิสิกส์แบบ fixed timestep 60Hz, กล้อง, การชน, การระเบิด
   - `UIScene` แถบข้อมูลและปุ่มต่างๆ (HUD), เมนู, หน้าต่างผลลัพธ์ แยกกล้องออกมาจึงไม่ซูมตามฉาก

ใช้ Matter.js แทน Arcade Physics เพราะ Arcade หมุนวัตถุไม่ได้ (ชนกันแบบกล่องตรงอย่างเดียว) บล็อกจึงล้มหรือหมุนตามจริงไม่ได้
