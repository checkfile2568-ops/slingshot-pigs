## โลกสีรุ้ง: เกมระบายสี (`coloring.html`)

| หมวด | รายละเอียด |
|---|---|
| โหมดถังสี 🪣 | แตะช่องว่างแล้วสีจะเทเต็มช่องนั้นทันที (Flood Fill แบบ scanline) สีไม่ทะลุเส้นขอบ และถ้านิ้วแตะโดนเส้น ระบบจะหาช่องที่ใกล้ที่สุดให้ |
| โหมดพู่กัน 🖌️ | ลากเมาส์หรือนิ้วเพื่อระบายได้อิสระ มีแถบปรับขนาดหัวพู่กัน และสวิตช์ “ระบายไม่เลอะนอกเส้น” ที่จำกัดพู่กันให้อยู่ในช่องที่เริ่มแตะ |
| เส้นขอบอยู่บนสุดเสมอ | ใช้ Canvas 2 ชั้น คือ `#paint` (ชั้นสี) กับ `#lines` (เส้นขอบดำโปร่งใส) ซ้อนอยู่บนสุด ระบายด้วยพู่กันแล้วเส้นก็ยังคมชัด และสีจะเติมเข้าไปใต้ขอบเส้นจนไม่มีขอบขาวแลบ |
| ภาพลายเส้น | บ้านน้อยแสนสุข · น้องแมวเหมียว · หุ่นยนต์ใจดี · ม้าหมุนสวนสนุก · ผีเสื้อในสวนดอกไม้ วาดด้วยโค้ด Canvas ทั้งหมด ไม่โหลดรูปจากภายนอก |
| จานสี | 14 สี (รวมสีขาวสำหรับลบ) และปุ่มเลือกสีเอง (Color Picker) ได้ไม่จำกัด |
| เครื่องมือ | ย้อนกลับได้หลายขั้น (สูงสุด 40 ครั้ง) · ล้างภาพ (กดย้อนกลับเพื่อเอาคืนได้) · บันทึกรูปเป็นไฟล์ .png |
| บันทึกอัตโนมัติ | งานของแต่ละภาพเก็บไว้ในเครื่อง ปิดแล้วเปิดใหม่ก็ระบายต่อได้ และภาพย่อในหน้าเลือกภาพแสดงงานที่ระบายไว้ |
| อุปกรณ์ | รองรับเมาส์และนิ้ว (Pointer Events มีสำรองด้วย Mouse/Touch Events) จัดหน้าจออัตโนมัติทั้งแนวตั้งและแนวนอน |

ทางลัดบนคีย์บอร์ด: `Ctrl/⌘ + Z` ย้อนกลับ · `[` `]` ปรับขนาดพู่กัน · `Esc` ปิดหน้าต่าง

**เพิ่มภาพใหม่:** เพิ่ม object ต่อท้าย `PICTURES` ใน `coloring.html` โดยวาดในพิกัด 1200 × 900 ตัวอย่าง:

```js
{ id: 'fish', name: 'ปลาน้อย', emoji: '🐟',
  draw(A) {
    A.ellipse(600, 450, 260, 150);                  // ตัวปลา
    A.poly([[340, 450], [180, 330], [180, 570]]);   // หาง
    A.circle(740, 410, 30); A.dot(748, 404, 12);    // ตา
  } },
```

ทุกชิ้นจะถูกเติมขาวแล้วลากเส้นดำตามลำดับ ชิ้นที่วาดทีหลังจึงบังชิ้นที่อยู่ข้างหลัง ต้องวาดทุกรูปทรงให้ปิดสนิท ถังสีจึงเทได้พอดีช่อง

## ABC ฟังแล้วทาย (`abc.html`)

| หมวด | รายละเอียด |
|---|---|
| โจทย์ปริศนา | กดชิงช้าสวรรค์ แล้วเครื่องจะสุ่มอ่านตัวอักษรภาษาอังกฤษ (en-US) ด้วย Web Speech API กดซ้ำเพื่อฟังอีกครั้งได้ |
| แป้น A–Z | ปุ่มใหญ่ทั้ง 26 ตัว กดแล้วอ่านออกเสียงทันที และจัดขนาดให้พอดีกับทุกจอ |
| Phonics | ทายถูกจะได้ยิน “Correct! B is for Banana” พร้อมการ์ดคำศัพท์ รูป และคำแปลไทยครบ A–Z |
| กติกา | ทายถูกได้ ⭐ และเปลี่ยนข้ออัตโนมัติใน 2 วินาที ทายผิดปุ่มจะเป็นสีแดงพร้อมคำว่า Try Again ผิดครบ 3 ครั้งปุ่มคำตอบจะกระพริบใบ้ |
| เพลง ABC | ปุ่ม 🎵 เปิด/ปิดทำนองเพลง ABC ที่สังเคราะห์ด้วย Web Audio API ตัวอักษรจะเต้นตามจังหวะ และตัวที่กำลังร้องจะเรืองแสง |

> เสียงอ่านมาจากเครื่องของผู้เล่นเอง แนะนำให้เปิดด้วย Chrome หรือ Safari ถ้าเบราว์เซอร์ไม่มีเสียงภาษาอังกฤษ (เช่น เบราว์เซอร์ในแอปแชตบางตัว) เกมจะแสดงตัวอักษรบนชิงช้าสวรรค์ให้ดูแทน

## เกมหนังสติ๊กเดิม: ถล่มป้อมหมูโจร 🐦💥🐷

เกมหนังสติ๊กยิงนกถล่มป้อมหมูโจรยังอยู่ครบ เปิดได้จากหน้าเลือกเกม หรือโดยตรงที่ `slingshot.html` สร้างด้วย **Phaser 3.90 + Matter.js** และไม่ต้อง build

มีชื่อเล่นและคะแนนแยกตามชื่อเล่นในเครื่องนั้น ๆ เลือกได้ในเมนู “ผู้เล่น / คะแนน” โดยไม่ต้องกรอกชื่อก่อนเริ่มเล่น และกดปุ่มรูปบ้านเพื่อกลับหน้ารวมเกม

## 🔧 ต่อยอด

ค้นหาคำว่า `🔧 ต่อยอด` ใน `slingshot.html` จะเจอจุดสำหรับต่อยอดเกมหนังสติ๊ก

**เพิ่มด่าน:** เพิ่ม object ใหม่ต่อท้าย `LEVELS` ได้เลย ระบบเลือกด่าน การปลดล็อก และการนับดาวจะรองรับให้อัตโนมัติ

```js
{ name: 'ด่านของฉัน', width: 1600, birds: ['pilot', 'dash', 'boom'],
  build(o) {
    // y = ระยะจากพื้นถึงขอบล่างของชิ้นงาน
    const top = room(o, 1000, 0, 160, 100, 'stone', 'wood');  // ห้อง: เสา 2 ต้น + คาน (คืนค่าความสูงขอบบน)
    o.push(pig(1000, 0, 'helmet'), pig(1000, top));
    o.push(blk('tnt', 1150, 0, 40, 40), tri('wood', 1000, top, 100, 50), ball('stone', 900, 0, 36));
    o.push(rock(1300, 0, 300, 120));                            // พื้นยกสูง (ทำลายไม่ได้)
  } },
```

| อยากเพิ่ม | แก้ที่ |
|---|---|
| วัสดุใหม่ | `MATERIALS` (ค่า hp, ความหนาแน่น, คะแนน) และเพิ่มวิธีวาดใน `drawBlock()` |
| หมูชนิดใหม่ | `PIG_TYPES` และเพิ่มหน้าตาใน `drawPig()` |
| นกชนิดใหม่ / พลังใหม่ | `BIRD_TYPES` + `drawBird()` + เพิ่ม `case` ใน `useAbility()` |
| ความแรงหนังสติ๊ก / ความเสียหาย / รัศมีระเบิด | `CFG` |

## โครงสร้างเกมหนังสติ๊ก (`slingshot.html`)

1. **ค่าคงที่และข้อมูลเกม:** `CFG`, `MATERIALS`, `PIG_TYPES`, `BIRD_TYPES`, `LEVELS`
2. **บันทึก / เสียง / เต็มจอ:** `Save` (localStorage), `Sfx` (WebAudio), `FS`
3. **กราฟิก:** ฟังก์ชัน `draw*()` วาดลง Canvas ที่ความละเอียด 2 เท่า (`Tex`)
4. **ฉาก:**
   - `BootScene` เตรียมภาพทั้งหมด
   - `TitleScene` หน้าเมนู
   - `GameScene` ตัวเกม: ฟิสิกส์แบบ fixed timestep 60Hz, กล้อง, การชน, การระเบิด
   - `UIScene` แถบข้อมูลและปุ่มต่างๆ (HUD), เมนู, หน้าต่างผลลัพธ์ แยกกล้องออกมาจึงไม่ซูมตามฉาก

ใช้ Matter.js แทน Arcade Physics เพราะ Arcade หมุนวัตถุไม่ได้ (ชนกันแบบกล่องตรงอย่างเดียว) บล็อกจึงล้มหรือหมุนตามจริงไม่ได้
